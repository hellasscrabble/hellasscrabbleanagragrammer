# hellasscrabbleanagrammer.gr

Στατική, responsive web εφαρμογή και PWA για έλεγχο ελληνικών λέξεων και αναγραμματισμό. Δεν χρειάζεται Python server: το περιβάλλον και η αναζήτηση εκτελούνται στον browser.

## Παραγωγή λεξικού και εικονιδίων

Από τον βασικό φάκελο του έργου, με εγκατεστημένα τα πακέτα του `requirements.txt`, εκτέλεσε:

```powershell
python site/build_dictionary.py
```

Το script διαβάζει την πρώτη στήλη ως λέξη και τη δεύτερη ως ερμήνευμα από το `ΒΑΣΗΛΕΞΕΩΝ (1).xlsx`, και δημιουργεί `site/data/words.tsv` και τα αρχεία εικόνας στο `site/assets/`.

Για κοινή χρήση χωρίς φιλοξενία ή εγκατάσταση Python στον υπολογιστή του παραλήπτη, δημιούργησε ένα ενιαίο HTML:

```powershell
python site/build_standalone.py
```

Θα δημιουργηθεί στον βασικό φάκελο το `hellasscrabbleanagrammer-standalone.html`. Μπορείς να το στείλεις ως αρχείο· ο παραλήπτης το ανοίγει με διπλό κλικ στον browser. Περιλαμβάνει το λεξικό και τις εικόνες, λειτουργεί εκτός σύνδεσης, αλλά δεν μπορεί να εγκατασταθεί ως PWA από `file://`.

## Τοπική προεπισκόπηση

Άνοιξε τερματικό στον βασικό φάκελο και τρέξε:

```powershell
python -m http.server 8000 --directory site
```

Έπειτα άνοιξε `http://localhost:8000`. Το `file://` δεν λειτουργεί σωστά για το λεξικό και το service worker.

Στα Windows μπορείς επίσης να κάνεις διπλό κλικ στο `run_web_preview.bat` από τον βασικό φάκελο. Άφησε ανοιχτό το παράθυρο server όσο χρησιμοποιείς την προεπισκόπηση· πάτησε Ctrl+C για να τη σταματήσεις.

## Δημοσίευση στο GitHub Pages

Ο φάκελος είναι έτοιμος για στατική φιλοξενία. Το workflow `../.github/workflows/deploy-site.yml` δημοσιεύει τον φάκελο `site/` στο GitHub Pages όταν υπάρχει push στο `main`.

1. Ανέβασε το έργο σε GitHub repository και ενεργοποίησε το GitHub Pages με πηγή **GitHub Actions**.
2. Στις ρυθμίσεις **Pages**, επαλήθευσε και δήλωσε το custom domain `hellasscrabbleanagrammer.gr`.
3. Στον πάροχο του domain, πρόσθεσε τις εγγραφές DNS που δίνει το GitHub. Για apex domain, η τρέχουσα τεκμηρίωση GitHub ζητά A records προς `185.199.108.153`, `185.199.109.153`, `185.199.110.153` και `185.199.111.153`. Αν θέλεις και `www`, πρόσθεσε CNAME προς το `<όνομα-λογαριασμού>.github.io`.
4. Περίμενε να ενημερωθεί το DNS και να ενεργοποιηθεί το HTTPS από το GitHub Pages.

Μην αλλάξεις DNS εγγραφές πριν δηλώσεις/επαληθεύσεις το domain στις ρυθμίσεις GitHub Pages. Οι αλλαγές DNS μπορεί να χρειαστούν έως 24 ώρες.

## Εγκατάσταση στο κινητό

Μετά τη δημοσίευση μέσω HTTPS, άνοιξε τη διεύθυνση στο κινητό. Σε συμβατό browser χρησιμοποίησε «Προσθήκη στην αρχική οθόνη» ή «Εγκατάσταση εφαρμογής». Το service worker αποθηκεύει τα αρχεία και το λεξικό για χρήση εκτός σύνδεσης μετά την πρώτη επιτυχημένη φόρτωση.

## Blogger

Μετά τη δημοσίευση, αντέγραψε το περιεχόμενο του `blogger-embed.html` σε Blogger > Διάταξη > Προσθήκη gadget > HTML/JavaScript. Ο σύνδεσμος κάτω από το πλαίσιο ανοίγει την εφαρμογή αυτόνομα, ώστε ο επισκέπτης να μπορεί να την εγκαταστήσει ευκολότερα.
