# Έλεγχος ελληνικών λέξεων

Μικρή εφαρμογή Python με γραφικό περιβάλλον για τη λίστα `ΒΑΣΗΛΕΞΕΩΝ (1).xlsx`.

## Εκκίνηση

1. Εγκατέστησε Python 3.10 ή νεότερη.
2. Άνοιξε τερματικό στον φάκελο της εφαρμογής και εκτέλεσε:

   ```powershell
   python -m pip install -r requirements.txt
   python app.py
   ```

Εναλλακτικά, στα Windows κάνε διπλό κλικ στο `run_app.bat`. Αν υπάρξει σφάλμα, το παράθυρο θα μείνει ανοιχτό ώστε να μπορείς να διαβάσεις το μήνυμα.

Η εφαρμογή φορτώνει αυτόματα το πρώτο `.xlsx` αρχείο που βρίσκεται στον ίδιο φάκελο. Μπορείς επίσης να επιλέξεις άλλο αρχείο από το κουμπί «Επιλογή αρχείου Excel…». Για το λογότυπο και το εξώφυλλο χρειάζονται επίσης τα αρχεία `ΕΛΑ ΣΚΡΑΜΠΛ LOGO.png` και `oi-lekseis-2-8-grammaton-scrabble.jpg` στον ίδιο φάκελο.

## Λειτουργίες

- Ελέγχει αν μια λέξη υπάρχει στην πρώτη στήλη του πρώτου φύλλου του Excel. Αγνοεί τόνους και κεφαλαία/πεζά.
- Το κουμπί «Ερμηνεία» εμφανίζει το περιεχόμενο της δεύτερης στήλης για τη λέξη, όταν υπάρχει.
- Βρίσκει λέξεις από 2 έως 8 γράμματα, χρησιμοποιώντας μέρος ή όλα τα διαθέσιμα γράμματα. Η είσοδος για αναγραμματισμό περιορίζεται σε 8 χαρακτήρες συνολικά, μαζί με τα `*`.
- Εμφανίζει τα αποτελέσματα σε γραμμές ανά μήκος λέξης.
- Το `*` αντικαθιστά ένα οποιοδήποτε γράμμα. Επιτρέπονται έως δύο `*`.
- Ελέγχει ότι η είσοδος περιέχει ελληνικούς χαρακτήρες. Για αναγραμματισμούς επιτρέπεται επίσης το `*`.

Η εφαρμογή χρησιμοποιεί το πρώτο φύλλο και την πρώτη στήλη ως λεξικό.

Πηγή λεξικού: [«Οι λέξεις 2-8 γραμμάτων» – Ελληνικό Αγωνιστικό Σκραμπλ](https://www.openbook.gr/oi-lexeis-2-8-grammaton-scrabble/). Πάτησε στο εξώφυλλο ή στον σύνδεσμο μέσα στην εφαρμογή για να ανοίξεις την πηγή.
